搜「泰拉瑞亚开服教程」的人，卡住的地方通常不在游戏本身。

这篇教程把三条路线摊开讲清楚，重点放在最后一条——直接在云服务器上用面板开服。这条路不需要公网 IP、不需要路由器设置、不需要本地电脑 24 小时开机，步骤少到可以边看边做。

## 为什么大多数教程没告诉你：面板服比 VPS 更省事

云服务器开泰拉瑞亚，有两种形态可选，很多人默认想到的是第一种，其实第二种更适合新手。

**VPS 游戏云**：给你一台完整系统权限的机器，Windows 或 Linux 都行，理论上什么都能装。代价是环境要自己配——Windows 下要先装对应版本的 .NET Framework 运行库，不然服务端一启动就闪退；Linux 下要自己 wget 下载服务端、解包、`chmod +x`、再用 screen 挂后台。不是难，是坑多。

**面板游戏云**：基于容器化技术（Docker / K8S），通过网页面板管理。服务端是选好游戏类型之后自动下载安装的，配置项在网页上点一点就改完，还带文件管理、SFTP 连接、备份还原和一键重装切换游戏。

## 配置怎么选：按在线人数倒推，别一上来就顶配

泰拉瑞亚对硬件的要求比 Minecraft 轻不少。它是个 2D 游戏，服务端主要是跑世界逻辑和同步，不像 MC 那样吃单核性能。

社区里比较一致的实践是：**2 核 4G 这个档位，原版或者轻量插件服撑住十来个同时在线没问题**，日常 4~8 人的朋友服绰绰有余。TShock 服在这个配置上跑到 20 人以内也是有人实测过的。

几个具体建议：

- **只和朋友玩、不装模组**：2 核 4G 起步，硬盘给到 20G 以上。
- **要装 TShock 管权限、防熊**：还是 2 核 4G，但 CPU 选单核睿频高一点的机型，TShock 的插件和命令处理会更跟手。
- **要开 tModLoader 模组服**：往上加。灾厄、瑟银这类大型模组会把内存和 CPU 占用拉高一大截，4 核 8G 更稳妥。
- **硬盘别抠**：默认给的系统盘加数据盘，世界文件本身不大，但加上备份目录、日志、模组包，10G 很快见底。硬盘扩容是按量计费的，一开始多给一点比中途迁移省心。

## 实操：从下单到朋友进服

流程比想象中短。

1. **注册并领券**。注册雨云账号后绑定微信，会拿到一张首月 5 折券，没有额外门槛。
2. **下单**。进控制台的「游戏云 → 购买游戏云」。服务器类型选**面板游戏云**，游戏类型选 **Terraria 泰拉瑞亚**，区域默认江苏宿迁，再选机型、计费模式、配置和购买时长。
3. **进面板**。买完之后在「云产品 → 游戏云 → 我的游戏云」能看到实例，页面上有面板地址和账号密码。点进去用 MCSManager 的账号登录。
4. **开启实例**。在实例卡片上点「管理」，然后点「开启实例」。第一次启动会自动下载安装服务端，控制台里出现 `Done` 字样就是起好了。
5. **拿地址和端口**。回到雨云控制台，复制服务器地址和端口。这个才是要发给朋友的连接信息，不是本地那个 7777。
6. **好友进服**。游戏里点「多人游戏 → 添加服务器 / 通过 IP 加入」，填地址和端口，接受。对方角色是旅行模式的话记得建个旅行角色，否则进不去。

给服主权限：在面板终端底部的命令输入框敲 `op 玩家名字`，回车就行。

## 服务端三种类型，别选错

面板里泰拉瑞亚有几个选项，选错了后面很麻烦：

- **原版（Terraria）**：纯净服，最省资源，朋友之间玩够了。
- **TShock**：带权限、封禁、组队、传送等管理功能，开公开服或者防熊必选。
- **tModLoader**：模组服。所有进服玩家的模组列表和版本必须完全一致，少一个都连不上。

有一点要注意：如果你要用自己现成的服务端文件替换上去，在「文件管理」里替换 `ServerPlugins` 和 `tshock` 这类文件夹就够了，**不要动启动脚本**。面板里的启动脚本和核心文件都是 Linux 版本，删掉或者换成 Windows 版本，服务端直接起不来。

## 端口映射：泰拉瑞亚的 7777 到底去哪了

这是新手最容易懵的一步。

泰拉瑞亚服务端默认监听 **7777** 端口，客户端默认也按这个端口找。但如果你买的是 NAT 模式的机器，公网 IP 是和其他用户共用的，只有一个独立的公网端口映射给你——不可能把所有人的 7777 都分出去。

所以做法是：在控制台的「NAT 端口映射」里新建一条规则，把**内网端口 7777** 映射到一个**任意的外网端口**（可以自定义，也可以让系统随机分配），协议选 TCP+UDP。

映射建好之后，发给朋友的连接信息就是「**映射公网地址 : 外网端口**」，两个都要带上，缺一个都连不上。

想省掉这一步也行，加购一个独立公网 IP 就能直接用 7777。但宿迁机房的独立 IP 是 150 元/月，比服务器本身还贵，纯朋友服没必要。

面板游戏云通常自带多条 NAT 映射，配置起来比 VPS 更省事。改完映射规则后建议重启一次实例让它生效。

## 存档比服务器值钱，备份别偷懒

一个跑了几个月的世界，丢掉的代价远超过一台服务器一个月的租金。两个动作值得做：

**开自动备份。** 面板里的备份还原功能可以定期打包存档。手动做的话，把世界目录整个压缩存一份，另外单独复制 `.wld` 和 `.bak` 文件——更新版本或者换模组之前，这一步别省。

**设一个每日自动重启。** 服务端长期运行会积累内存占用，凌晨重启一次能明显降低卡顿概率。Linux 环境下用 cron 定时重启服务，Windows 环境下用任务计划程序跑批处理，都是几分钟的事。

## 常见问题

**朋友连不上怎么办？** 按顺序查三件事：发给他的地址和端口是不是"映射公网地址 + 外网端口"；NAT 映射规则有没有生效，改完规则有没有重启实例；双方游戏版本是否完全一致，版本不同会直接报错。

**模组服进不去。** 九成是模组列表不一致。所有玩家必须装完全相同的模组和版本，服务器端用 `enabled.json` 和 `install.txt` 管理，客户端对照着来。

**能开多少人的服？** 泰拉瑞亚服务端默认最大玩家数是 16。实际能带多少人看配置，2 核 4G 跑原版，十来个人同时在线是常见水平。

**服务器可以随时升级吗？** 可以。CPU、内存、容量都支持弹性升级，面板服还支持切换机型。先按最小可用配置跑起来，感觉不够再加，比一开始买顶配更划算。

## 什么情况下别买云服务器

如果你们就是两三个人、晚上打两小时、周末才凑得齐，本地开服加 Steam 好友邀请完全够用，花这个钱没必要。

真正值得上服务器的信号有几个：你要一个 24 小时在线、随时有人能进的公共世界；要装模组或者用 TShock 做权限管理；房主电脑不能长时间挂着；家里没有公网 IP 又不想天天折腾内网穿透。

满足其中任意一条，面板开服就是最省事的那条路——十分钟能搞定的东西，没必要在路由器管理页面上耗一晚上。
